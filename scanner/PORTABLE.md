# Переносной анализатор HDD — Windows 10/11 x64

Комплект `dist/HDDScanner-Windows-x64.zip` включает Python: установка, Codex,
интернет и права администратора на рабочем компьютере не нужны. Администратор
может понадобиться для доступа к информации о носителе; если Windows запрещает
запрос, сканирование остановится. Права исходных файлов программа не меняет.

## Перед раздачей дисков

На основном компьютере назначьте каждому физическому диску уникальный номер.
HDD01 и HDD02 уже заняты. Например, второму компьютеру выдайте HDD03–HDD08,
третьему HDD09–HDD14. Зафиксируйте выдачу в общем реестре и подпишите диски.
Не назначайте один номер на двух компьютерах. При первом старте проверьте
показанные серийный номер, размер, метку тома и назначенный номер, затем YES.
Новый сканер не связывает старые буквы дисков с новыми номерами.

## Запуск на другом компьютере

1. Перенесите ZIP флешкой, распакуйте **на внутренний диск** компьютера.
2. Запустите `SELF_TEST.cmd`. Должно быть OK. Эта проверка работает на временных
   искусственных файлах и не читает архивные диски.
3. Подключите архивный HDD. Запустите `START.cmd`, выберите 1.
4. Введите заранее назначенный номер (например HDD03) и текущую букву (например E).
5. Проверьте устройство, введите YES. Сохраните напечатанный путь JOB.

Результаты лежат в `%LOCALAPPDATA%\HDDScanner\results\HDDxx_<уникальный код>`.
Там сохраняются метаданные и хеши, а не копии фото и видео. Нужен запас места
на внутреннем диске под базы (зависит от количества и длины путей).
Нельзя выбирать архивный том для результатов. Не меняйте файлы и подключение
диска во время прохода. Программа препятствует автоматическому сну только пока
работает; ручной сон, закрытие крышки и отключение питания этим не исключаются.

Метаданные собираются для всех доступных обычных файлов, включая мелкие;
системные/служебные папки, reparse points и имена `.env` исключаются.
Полный SHA-256 считается для фото/видео из общей политики размером от 1 МиБ.
Мелкие медиа и сопроводительные документы остаются в каталоге метаданных,
но пока не имеют хешей. Правила совпадают с текущими выборками HDD01/HDD02.
Никакие документы не перемещаются в «НЕ ФОТО и НЕ ВИДЕО» на этом этапе.

## Возобновление и ошибки

START → 2 → полный путь сохранённой папки JOB. Буква может измениться:
сканер ищет носитель по аппаратному серийному номеру и размеру, затем проверяет
серийный номер и размер тома. UniqueId не используется как постоянный ключ.
При неоднозначности или смене идентичности — остановка для ручной проверки.
При смене USB-моста аппаратный серийный номер может измениться: не исправляйте
job.json наугад, верните исходное подключение либо разберите это на основном ПК.

Хеш каждого завершённого файла сохраняется отдельной транзакцией. При повторном
запуске проверяются размер, дата изменения и идентификатор файла; подходящие
записи используются повторно. Незавершённый файл читается с начала. Если
прерван именно сбор метаданных, он повторяется; готовая база хешей сохраняется.
Первая ошибка чтения останавливает хеширование, не скрывайте её повторными
запусками без проверки. Список недоступных каталогов остаётся в отчёте;
complete_with_inventory_errors не означает полный охват диска.

Один процесс на диск. Разные диски можно обрабатывать в разных окнах; базы
у каждого JOB отдельные. Не запускайте разные JOB для одного носителя параллельно.
Не удаляйте местные результаты до подтверждения импорта на основном компьютере.

## Передача флешкой

После завершения START → 3 → путь JOB → папка на флешке, например `F:\HDD_RESULTS`.
Экспорт разрешён только после завершения и закрытия баз. Рядом с двумя SQLite
будут JSON и `checksums.json`. Контрольные суммы проверяют целостность передачи,
но не удостоверяют отправителя. Повторный экспорт делайте в другую папку.

На основном ПК START → 4 → папка экспортированного JOB на флешке →
`C:\course_claude\Диски с фото и видео - оптимизация каталог\Каталог дисков\Импорт`.
Импорт сверяет SHA-256 каждого файла и сохраняет отдельную копию. Он **не**
перезаписывает реестр и не объединяет автоматически потенциально конфликтующие
номера. Перед общим сравнением необходимо сверить номер с физической идентичностью
из job.json и устранить дубли номеров. Старые hashes.sqlite HDD01/HDD02 совместимы
по структуре таблицы hashes; их исходные результаты остаются на месте.

## Воспроизводимая сборка

На машине с Python: `python scanner/build_portable.py` из корня проекта.
Сборщик скачивает официальный Python 3.13.17 embeddable x64 и сверяет SHA-256
с опубликованным на python.org. Сторонних Python-пакетов нет. Сканер работает
офлайн, runtime не применяется для сетевых задач. ZIP, runtime и личные результаты
не публикуются в Git; исходники, тесты и инструкция публикуются.

Версия 1.0.0. Разрушительных операций, перемещения и удаления исходников нет.
