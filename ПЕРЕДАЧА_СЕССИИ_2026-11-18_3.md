## Что изменено в коде (единственное изменение за сессию)

Замечание владельца: кнопка «Пересчитать хеш» открывала окно шириной в три экрана.

**Причина:** длинная подпись `QLabel` без переноса строк. Такая подпись требует всю ширину текста в одну строку, и Qt
растягивает под неё окно. В «Пересканировать папки» подпись — это список папок через «;» (их бывает 30 — отсюда три
экрана), в окне спорных файлов — длинное пояснение сверху.

**`catalog/rescan_dialog.py`**, строки 40–42 (было одной строкой `lay.addWidget(QLabel(...))`):

```python
folder_line = QLabel(f'<b>{disk}</b>: ' + html.escape('; '.join(self.folders)))
folder_line.setWordWrap(True)            # длинный список папок не должен задавать ширину окна
folder_line.setMaximumWidth(820)
lay.addWidget(folder_line)
```

**`catalog/ui/razbor/dialogs.py`**, строки 55–60 (было `lay.addWidget(QLabel(...))` с длинным текстом):

```python
note = QLabel(f'<b>{esc(where)}</b>: где лежат файлы без хеша и '
              'неподтверждённые копии, из-за которых ответ «можно ли удалить» - «НЕТ» или «НЕДОСТАТОЧНО».'
              ' Пересканивание посчитает хеш у всех файлов этих папок.')
note.setWordWrap(True)                  # иначе окно расползается по ширине текста (замечание владельца 18.11)
note.setMaximumWidth(780)
lay.addWidget(note)
```

Ничего другого в коде не менялось: логика, числа, кнопки, тексты — прежние.

## Второе замечание владельца: «почему разнятся данные о количестве файлов» — разобрано, НЕ правилось

Снимок: ячейка «Копировать на диск H:» для источника **HDD09** (шаг 1 «Посчитать (27492)», шаг 2
«Посчитать хеш на H: (2887)»), а открылось окно **«Пересканировать папки - HDD45»** с числами 11 049 / 10 643 / 406 /
3 812 / 6 831.

**Числа сходятся между собой:**
- 11 049 — все файлы 9 папок HDD45 по описи;
- минус 406 (хеш берётся из прежней описи, без чтения) = **10 643** к чтению;
- из них файлы выбранных типов (фото, видео, документы) — **3 812** читаются (0,2 ГБ);
- остальные **6 831** (2,0 ГБ) — других типов, останутся без хеша;
- проверка: 3 812 + 6 831 = 10 643; 0,2 + 2,0 ≈ 2,19 ГБ (округление до десятых).
- 27 492 — файлы без хеша на **другом** носителе (HDD09), к числам окна HDD45 не относятся.

**Почему открылось окно HDD45:** по снимку это шаг 2 — проверка файлов **на архиве** H: (= HDD45), а не на носителе.
Так и задумано. 2 887 — кандидаты «то же имя и размер»; в окне 11 049, потому что сканер читает папки целиком.
ОГОВОРКА: что владелец нажал именно кнопку шага 2, установлено по снимку, а не по журналу — точный маршрут нажатия
не проверен.
