# Программа «Архив дисков»: полное описание (состояние на 18.11.2026, вечер — после первых правок отладки)

Документ для владельца и для любой нейросети (Claude, ChatGPT и др.), которая продолжит работу. Читается без
других файлов. Подробности по отдельным темам — в документах из раздела 12.

Репозиторий: https://github.com/wadimka78/hdd-opimization-foto-video (ветка `main`; коммиты — раздел 9).

---

## 1. Зачем программа

Владелец (не программист, Windows 10) сводит семейный фото- и видеоархив с ~57 старых носителей (жёсткие диски
HDD01…HDD78, флешки Flash01…) на **архивные диски** и раскладывает остальное по тематическим дискам.

Главные архивные диски:
- **HDD45** «Бэкап фото и видео», 16 ТБ (обычно буква H:) — семейный архив, копия 1;
- **HDD77** «Путешествия 2018 - 2025», 14 ТБ — семейный архив, копия 2;
- другие: HDD78 «Работа Сафари 6ТБ», HDD55 «My Book» (фильмы) и т.д.

Основа всего — **описи**: каждый носитель заранее прочитан сканером (список всех файлов, размеры, даты, SHA-256 у
фото и видео, а при выборе — и у других типов). Программа работает по описям и почти не читает диски.

**Главные правила (решения владельца):**
- Программа **НИЧЕГО НЕ УДАЛЯЕТ**. Удаляет владелец сам, потом подтверждает в программе.
- Перемещения — только в пределах одного диска.
- Каждая копия сверяется по **SHA-256**. Копировать можно только файлы, у которых хеш посчитан.
- Секреты не читаются и не выводятся (`C:\secrets\.env`).

## 2. Как запустить

```
pythonw catalog\app.py
```
(из корня проекта; нужен Python 3 и PySide6). Окно «Архив дисков». Командная строка для тех же расчётов —
`py catalog\hashbase.py <команда>` (список: `py catalog\hashbase.py -h`).

## 3. Понятия

| Слово | Что значит |
|---|---|
| **Носитель / источник** | диск или флешка, с которого копируем (например HDD09 «Монтаж - SN850», 4,19 млн файлов) |
| **Архивный диск** (в коде — «направление») | куда копируем. У каждого номер **А1, А2…** (в базе хранится как «Н1, Н2…», на экране показывается «А»), имя, диск(и) и набор «что копировать» |
| **Что копировать** | типы файлов в настройках архивного диска: «Фото», «Видео», «Документы — только рядом с фото и видео», или «Все файлы (кроме программ и временных)» |
| **Хеш (SHA-256)** | «отпечаток» файла; одинаковый хеш = одинаковое содержимое. По нему программа знает, что копия есть и она целая |
| **Без хеша** | файл, у которого сканер не посчитал SHA-256 (его тип не выбирали при сканировании или скан был без хешей). Есть ли его копия — проверить нельзя |
| **Уже есть на H:** | на архивном диске лежит подтверждённая копия с тем же SHA-256 |
| **Спорные** | файлы, чью копию нельзя проверить по SHA-256: без хеша на носителе, тёзки без хеша (то же имя и размер), непроверенные копии на архивных дисках |
| **ПЕРЕНОС с других дисков** | папка на архивном диске, куда кладутся копии: `H:\ПЕРЕНОС с других дисков\<носитель>\<путь как на носителе>` |
| **Скопировано на …** | служебная папка на НОСИТЕЛЕ: после копирования и проверки папка носителя переносится туда (например «Скопировано на Семейный архив 45»). Удаляет её владелец сам |
| **Задание** | папка в «Запускаемые скрипты» со списком файлов и скриптом PowerShell; копирует, сверяет SHA-256, пишет журнал |
| **База** | `Каталог дисков\_БАЗА\хеши.sqlite` — собирается из описей, журналов заданий и таблиц владельца |

## 4. Порядок работы (три шага)

Вверху вкладок «Назначить Архивный диск», «Выбор источников», «Копирование» — плашки трёх шагов; текущий шаг
голубой, щелчок по другому открывает его вкладку.

1. **Назначить Архивный диск** — отметить галочкой ОДИН архивный диск, куда будем копировать.
2. **Выбор источников** — выбрать носитель, отметить галочками папки, проверить, что всё поместится и у всех файлов
   есть хеш, нажать «Начать копирование…», подтвердить.
3. **Копирование** — копирование идёт в своём окне PowerShell (можно закрыть программу — оно продолжится); здесь
   прогресс, скорость, сколько осталось, ошибки; после копирования — перенос папки на носителе в «Скопировано на …».

### 5.1 «Назначить Архивный диск» (`catalog/overview_page.py`, `directions_section.py`, `directions_look.py`)

- Карточка на каждый архивный диск: галочка · «А1 Архивный диск №1» · строка диска «H: Бэкап фото и видео — HDD45 ·

  «📁 Файлы будут скопированы в папку H:\ПЕРЕНОС с других дисков» (не подключён — «на диск HDD78 в папку
  «ПЕРЕНОС с других дисков»»).
- Кнопки карточки: «Изменить» (имя, описание, что копировать; диск не меняется), «Подробнее о содержимом диска…»
  (окно «Содержимое выбранного диска»: всего ГБ, копии проверены по хешу / не проверены / хеш не считался,

- Отмеченная карточка — светло-зелёная; щелчок по карточке ставит/снимает галочку. Внизу «Копируем на: …» и
  «Дальше: выбрать папки на носителе →».
- Ниже — «Требует внимания» (прерванные задания и задания с ошибками).
- Подвал окна: «База собрана 15.11 22:52: носителей 57, файлов 11,3 млн».

### 5.2 «Выбор источников» (пакет `catalog/ui/razbor/`)
- Плашка «Диск назначения: H: Бэкап фото и видео — HDD45, 16 ТБ · свободно 443,9 ГБ».
- «Выберите носитель» (список носителей базы; подключён — с буквой), строка описи («опись от 08.11.2026, полная ·
  4 191 290 файлов, 2 992,0 ГБ»).
- **Строка «Из содержимого HDD09 нет на H: N файлов (ГБ)»** — файлы выбранных в настройках А1 типов без подтверждённой
  копии на H:; ниже «Типы файлов: «фото», «видео», «документы рядом с ними» — согласно настройкам А1», зелёным «в
  отмеченных папках … — будут скопированы на H:», красным «в неотмеченных папках … — не попадут на H:» +
  «Показать по папкам» (окно-дерево), серым — файлы без хеша в неотмеченных (`view_missing.py`).
- «Что копировать с носителя»: «Только выбранные папки» / «Все папки» / «Все, кроме выбранных».
- Пояснение цветов над деревом (друг под другом): зелёный — папка отмечена, из неё есть что копировать; розовый —
  отмечена, но копировать нечего (всё уже есть на H: или нет файлов выбранных типов).
- Дерево папок носителя с галочками (столбцы: Файлов, ГБ, Фото, Видео, Прочее, Уже есть). Shift/Ctrl — несколько папок;
  папку можно перетащить в ячейку справа. Отметки пишутся в базу сразу (кнопки «Отменить последнее» больше нет).
- Справа ячейка **«Копировать на диск H: …»** (`view_cell.py`, `cell_parts.py`, `texts_cell.py`):
  - под «Архивный диск №1, HDD45» — «Что копировать:» голубыми плашками и «Изменить…» (то же окно настроек, что на
    первой вкладке; мелко: «Настройка А1 — общая для всех носителей; уже созданные задания не меняются»);
  - «Отмечено N папок · файлов · ГБ», строки «Копировать на H:», «Уже есть на H:», «Не копируются (другой тип)»
    (у каждой «Показать» — окно «Список файлов»), «Поместится / Не помещается» (с запасом 2 ГБ / 1 % и местом
    незапущенных заданий);
  - рамка **«Перед копированием»**: шаг 1 «Посчитать хеш на <носитель> — обязательно» (✖ + кнопка «Посчитать (N)» →
    ✓; N — файлы носителя без хеша, которые пойдут на H:; пока не сделан — «Начать копирование…» неактивна, «станет
    доступно после шага 1»); шаг 2 «Посчитать хеш у файлов на H: с тем же именем и размером — по желанию» (только если
    такие есть; кнопка «Посчитать хеш на H: (K)»; не блокирует копирование).
- **Окно «Посчитать хеш — <носитель>»** (шаг 1; `dialog_hash.py`, `texts_hash.py`): «Посчитать хеш у N файлов на
  HDD18 (I:)», сколько файлов прочитает сканер (он читает папку целиком — хеш заодно появится и у соседних файлов),
  «Подробнее…», «Посчитать» / «Отмена»; затем «Прочитано x из y» и «Остановить»; «Остановлено» — «Продолжить»; итог
  только после приёма скана в базу и повторной проверки: «✓ Хеш есть у всех… нажмите «Начать копирование…»» или «Без
  хеша осталось N — Показать». Галочек типов и второго вопроса нет. Шаг 2 пока открывает общее окно «Пересканировать
  папки — HDD45» (с галочками типов) — короткое окно для него владелец отложил (18.11).
- **«Начать копирование…»** → окно подтверждения «Начать копирование: HDD09 → H: … (А1)»: таблица папок (копировать /
  ГБ / уже есть; «копировать нечего» — розовым; Итого), «Куда: H:\ПЕРЕНОС с других дисков\HDD09\…», место, хеш,
  примерное время (по скорости прошлых копирований на этот диск; нет истории — «время будет видно после начала»),
  большая кнопка «Подтвердить и начать копирование». После подтверждения: создаются новые задания (без дублей),
  запускаются новые + ждущие, открывается вкладка «Копирование». Перед созданием — повторная сверка оглавления
  носителя с описью (изменился — создание блокируется, предлагается пересканировать папки). Файлы:
  `dialog_start.py`, `texts_start.py`, `flow_tasks.py`.
- Внизу: пояснение «Спорные — …», «Спорные по всему носителю…», «Показать список».

### 5.3 «Копирование» (пакет `catalog/ui/tasks/`)
Плашки «Идёт / Ждут запуска / Прервано, с ошибками / Готово»; таблица заданий (что и куда, состояние со скоростью и
«осталось», сделано, ошибки); «Запустить отмеченные (N)», «Запустить все по очереди», «Открыть журнал», «Открыть
папку задания»; блок «Скопировано — можно переместить папку на носителе» (перенос в «Скопировано на …»); «Готово (N)»
свёрнутым списком. Проверки запуска: уже идёт; перемещение и копирование с одного носителя одновременно нельзя;
одни диски у нескольких заданий — лучше по очереди.

**«Отменить задание…»** (`service/jobs_cancel.py`, `ui/tasks/flow_cancel.py`, `texts_cancel.py`) — только для заданий
КОПИРОВАНИЯ в состояниях «не запускалось», «прервано», «готово с ошибками». Ничего не удаляется: папка задания
переносится в `Запускаемые скрипты\_Отменённые` (имя занято — « (2)»), строка — в `_Отменённые\отменённые задания.tsv`.
Перед переносом — повторная проверка, что задание не идёт и не стоит в очереди; папка занята окном PowerShell — «закройте
окно задания и повторите». Папки на «_» нигде не считаются заданиями; журналы отменённых база читает — уже скопированное
учтено, новое задание на ту же папку берёт только остальное.

### 5.4 «Диски и папки» (пакет `catalog/ui/disks/`)
Поиск папок по словам на всех дисках; таблица носителей (подключён, свободно, файлов, ГБ, сканирование); дерево папок
выбранного носителя (файлов, ГБ, «Без хеша», фото, видео, тексты, прочие, мусор, «Решение владельца» — метки «А1 …»).
Красная строка «Без хеша N фото и видео…» с кнопкой **«Досчитать хеш фото и видео (N)…»**; правый щелчок по папке —
«Досчитать хеш в этой папке…»; щелчок по числу «Без хеша» — список; в списке — «Досчитать хеш у выбранных…».
Неподключённый диск — эти кнопки неактивны. Внизу «Открыть в Проводнике», «Пересканировать выбранные…», «Чего нет на
дисках направления».

### 5.5 «Я сделал в Проводнике» (`explorer_*.py`)
Владелец сообщает, что сам скопировал/перенёс/удалил в Проводнике; программа сверяет по оглавлению и записывает в
журнал ручных операций.

### 5.6 «Команды» (`commands_page.py`, 1320 строк) — УЙДЁТ
Вопросы к базе и обслуживание. Решение владельца 17.11: вопросы о папке — в правый щелчок «Дисков и папок»,
обслуживание (сводка, обновить/пересобрать базу, список заданий) — в меню окна «Сервис»; потом вкладку удалить.
Сначала — макет и критики. Пока вкладка на месте.

## 6. Откуда берутся данные (новые диски, пересканирование)

1. Диск читает **портативный сканер** (`scanner\portable.py`, версия 1.6.1; `.exe` в `dist\` устарел — 1.3.2).
   Результат — папка с `inventory.sqlite` и `result.json`.
2. Папка результата должна лежать в `РЕЗУЛЬТАТЫ СКАНИРОВАНИЯ - сводные\<имя носителя>\<папка скана>\`.
   Папки с `_Архив` в пути пропускаются. Действует самая свежая ПОЛНАЯ опись носителя; частичный скан папок её
   дополняет, но не заменяет.
3. Программа при запуске и каждые 10 секунд, пока открыта, проверяет «подпись» источников (описи, журналы, таблицы);
   если изменилось — в фоне применяет только новое (иначе — полная пересборка, несколько минут). Внизу окна «Применены
   новые модули», подвал обновляется.
4. Пересканирование из окна («Пересканировать выбранные…», «Досчитать хеш…», «Посчитать хеш (N)») запускает сканер
   отдельным процессом: предпросмотр без чтения файлов → подтверждение → чтение только файлов выбранных типов без
   хеша (сохранённые хеши берутся из базы) → приём в базу. Сканер работает по папкам; файлы прямо в корне диска
   досчитывает только полная опись.

## 7. Как устроен код (кратко)

```
catalog/
  app.py                 главное окно, вкладки, подвал, приём новых описей
  ui_common.py           шаги (StepsBar), фоновые задачи, сторож зависаний
  disk_ui.py             подписи и цвета дисков, tb_text (ёмкость «как на наклейке»)
  overview_page.py, directions_*.py, disk_content_dialog.py, disk_table.py   — «Назначить Архивный диск»
  ui/razbor/  — «Выбор источников»: page.py (сборка), view_* (блоки), flow_* (запись, фон),
                model_* (данные), texts_* (тексты), dialog_start.py (окно «Начать копирование»)
  ui/tasks/   — «Копирование»;  ui/disks/ — «Диски и папки»;  ui/filelist/ — окно «Список файлов»
  service/    — данные для окна (чтение базы, запись таблиц владельца)
  hb_core/, hb_cmd/      — ядро базы и команды (hashbase.py)
  tests/, test_*.py      — тесты
scanner/                 — портативный сканер
Каталог дисков/_БАЗА/    — база и таблицы владельца (направления.tsv, решения.tsv, ручные операции.tsv …)
Каталог дисков/_ШАБЛОН копирования/  — PowerShell-шаблон копирования (Копировать.ps1, версия 2.8)
Запускаемые скрипты/     — задания копирования
```
Правило: файл кода ≤ 600 строк (цель 400). Правка текста/вида экрана — в одном небольшом файле
(`texts_*` / `view_*`). Карта всех файлов — `docs/СТРУКТУРА_ПРОГРАММЫ.md`.

## 10. Решения владельца, которые ждут работы

1. Убрать вкладку «Команды» (вопросы — правый щелчок в «Дисках и папках», обслуживание — меню «Сервис»); сначала макет.
2. Режимы «Один архив» / «Дуплекс» (45 и 77 одновременно, три папки «Скопировано на 45 / 77 / 45 и 77», сверка, что
   каждый файл есть на обоих); ручное удаление владельцем + кнопка «Подтвердить самостоятельное удаление».
3. Копировать каждый повтор файла внутри отмеченной папки (вариант Б), чтобы структура на архиве была полной.
4. В «Назначить Архивный диск» — отмечать только ОДИН диск (сейчас галочек можно поставить несколько).
5. «Выбор источников»: задания при неподключённом диске назначения — запретить; место чужих незапущенных заданий не
   считать.
6. Ёмкость неподключённого диска не показывается (объём известен только у подключённого) — хранить в базе.
7. Тексты «45 и 77» в командах и списке файлов (`hb_cmd/missing`, `directions`, `mklist`, `stats`, `service/filelist`,
   `family`) — заменить на «архивные диски», когда дойдём.
8. Сканер — вкладкой программы (позже); пересобрать `.exe` сканера.
9. Отложено владельцем 18.11: короткое окно для шага 2 «Посчитать хеш на H:» и понятная цепочка чисел в окне
   «Пересканировать папки» (11 049 всего → 406 с хешем из прежней описи → 10 643 к чтению → 3 812 выбранных типов /
   6 831 других; размеры округлены) — предложение Критиков.
10. Не проверено на деле: после «Отменить задание…» с именем « (2)» база, вероятно, пересоберётся целиком; в задании
    видно старое имя диска «Семейный архив 45» вместо «А1 Архивный диск №1»; смысл строки места «нужно 149,6 ГБ» при
    копировании 0,1 ГБ (запас + чужие задания) может быть непонятен.
Полный список и история — `ЖУРНАЛ_ДОДЕЛОК.md`.

## 11. Как работаем (для нейросети)

- Отвечать владельцу коротко, по-русски, без жаргона, фактами и числами.
- Замечание владельца → сначала запись в `ЖУРНАЛ_ДОДЕЛОК.md` → при неясности макет → код только после «да».
- Решения проверяют два критика (DeepSeek `deepseek-v4-pro` и GPT `gpt-6.1-sol`).
- Тесты и коммит — после каждого шага; на GitHub — только по слову владельца.
- Запись в настоящие данные (таблицы, база) — только после явного «да».
